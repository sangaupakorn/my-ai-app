# แผนพัฒนาระบบคำนวณระยะทางตามแนวถนนจริง (Real Road Routing)

ระบบคำนวณระยะทางและแสดงเส้นทางวิ่งจริงตามโครงข่ายถนน เพื่อให้ตัวเลขระยะทางและค่าจัดส่งตรงกับ Google Maps โดยไม่ต้องใช้ API Key และแสดงเส้นทางขับรถบนแผนที่อย่างชัดเจน

## User Review & Critical Decisions

> [!IMPORTANT] สรุปทางเลือกที่ลูกค้ายืนยันในขั้นตอนสัมภาษณ์
> - **ระบบเส้นทางถนนจริง (Routing Engine)**: ใช้ระบบโครงข่ายถนนจริง Open Source Routing Machine (OSRM Driving Engine) ใช้งานได้ฟรี ไม่มีค่าบริการรายเดือน และไม่ต้องใช้ Google Cloud API Key
> - **การแสดงผลบนแผนที่**: วาดแนวเส้นทางขับรถจริงตามโค้งถนน (Real Road Path) บนแผนที่ Leaflet แทนเส้นประเดิม เพื่อให้ลูกค้าเห็นเส้นทางรถขนส่งจากหน้าร้านสุโขทัยแสงอุปกรณ์ไปยังจุดหมายอย่างชัดเจน
> - **ระบบสำรอง (Fallback)**: หากเกิดกรณีเครือข่ายขัดข้อง ระบบจะสลับไปใช้การคำนวณสำรองอัตโนมัติทันที เพื่อให้ลูกค้ายังสามารถสั่งซื้อและคิดค่าส่งได้ต่อเนื่องไม่สะดุด

---

## 1. Overview & Core Concept

- **ปัญหาที่พบ**: เดิมระบบใช้สูตร Haversine คำนวณเส้นตรงทางอากาศแล้วคูณชดเชยคงที่ 1.18 เท่า (+18%) ทำให้เส้นทางที่เป็นถนนหลวงสายหลักตรงๆ (เช่น ทางหลวงหมายเลข 12) ได้ระยะทาง 4.8 กม. ซึ่งคลาดเคลื่อนจาก Google Maps ที่ได้ 4.3 กม.
- **เป้าหมาย**: คำนวณระยะทางจากโครงข่ายถนนจริง (Road Network Geometry) แบบเลี้ยวต่อเลี้ยว ทำให้ได้ระยะทาง 4.3 กม. ตรงกับ Google Maps ทันที
- **กลุ่มเป้าหมาย**: ลูกค้าและช่างที่สั่งซื้อสินค้าผ่านเว็บไซต์สุโขทัยแสงอุปกรณ์ และต้องการความมั่นใจในระยะทางและค่าจัดส่งที่โปร่งใสและตรงกับ GPS จริง

## 2. User Experience & Visual Design

- **การปักหมุดหรือวางลิงก์ Google Maps**:
  - เมื่อลูกค้าวางลิงก์ Google Maps, เลือกอำเภอจาก Dropdown, ดึงพิกัด GPS หรือลากหมุดบนแผนที่
  - ระบบจะยิงคำนวณเส้นทางรถวิ่งจริง (Driving Route) จากร้านสุโขทัยแสงอุปกรณ์ (`17.00929, 99.81127`) ไปยังจุดหมายทันที
- **การแสดงผลบนแผนที่ (Map Visualization)**:
  - แทนที่เส้นประเดิมด้วย **เส้นทางถนนจริง (Solid Curved Route)** สีน้ำเงินเข้ม/แดงสดใส พร้อมเส้นขอบเรืองแสง (Glow Effect) ที่ลากไปตามแนวถนนหลวงหมายเลข 12 และซอยต่างๆ อย่างสวยงาม
  - มีไอคอนหัวหมุดเริ่มต้น (ร้าน) และหมุดปลายทาง (ลูกค้า)
- **การแสดงตัวเลขระยะทางและค่าจัดส่ง**:
  - แสดงระยะทางถนนจริง เช่น **4.3 กิโลเมตร** (ปัดเศษทศนิยม 1 ตำแหน่งตามมาตรฐาน Google Maps)
  - คำนวณอัตราค่าจัดส่งตามโซนและเงื่อนไขส่งฟรีอย่างแม่นยำ
  - ระบุป้ายข้อความกำกับว่า *"ระยะทางตามเส้นทางถนนจริง (ตรงกับ Google Maps)"*

## 3. Key Product Decisions & Trade-Offs

- **การเลือกใช้ OSRM Driving Engine ผ่าน Backend Proxy**:
  - *เหตุผล*: ป้องกันปัญหา CORS บนเบราว์เซอร์, เพิ่มประสิทธิภาพด้วยระบบ Memory Cache (พิกัดเดียวกันไม่ต้องคำนวณซ้ำ), และทำงานร่วมกับทั้ง Vite Dev Server และ Production ได้ราบรื่น
  - *ข้อดี*: ฟรี 100%, อัปเดตโครงข่ายถนนสม่ำเสมอ, รองรับจุดเลี้ยวและทางเบี่ยงบนถนนในสุโขทัยและจังหวัดข้างเคียงครบถ้วน
- **ระบบ Fallback สำรองสองชั้น**:
  - ชั้นที่ 1: เรียกคำนวณเส้นทางถนนจริง (OSRM)
  - ชั้นที่ 2: หาก API ช้าเกิน 3 วินาที หรือไม่มีอินเทอร์เน็ต จะใช้การประมาณการระยะทางถนนที่มีความแม่นยำสูงสำรองทันที ไม่ปล่อยให้หน้าต่างค้าง

### การปรับปรุงไฟล์โค้ด (เมื่อได้รับอนุมัติ)
1. **`server.ts`**:
   - เพิ่ม Route `/api/route` สำหรับคำนวณระยะทางและรับพิกัดเส้นทางถนนจริง (GeoJSON) จากพิกัดร้านสุโขทัยแสงอุปกรณ์ไปยังพิกัดลูกค้า
2. **`src/utils/delivery.ts`**:
   - เพิ่มฟังก์ชัน `fetchRoadRoute(destLat, destLng)` สำหรับดึงระยะทางและเส้นทางถนนจริง
   - ปรับ `evaluateDelivery` ให้รองรับระยะทางจากถนนจริง
3. **`src/components/DeliveryMapPicker.tsx`**:
   - เมื่อพิกัดลูกค้าเปลี่ยน ให้เรียกคำนวณเส้นทางถนนจริง
   - เปลี่ยนจากการวาดเส้นตรงประ (`dashArray`) เป็นการวาดเส้นทางตามแนวโค้งถนนจริง (`polyline.setLatLngs(routePoints)`)
   - ปรับข้อความแสดงผลระบุระยะทางตามถนนจริงชัดเจน
